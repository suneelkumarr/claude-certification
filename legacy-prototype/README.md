# Legacy Prototype Archive

This directory contains the initial vanilla JavaScript, HTML, and CSS proof-of-concept files developed prior to migrating the application to React 18 + Vite.

### Archived Files
- `app.js` / `app.vanilla.js`: Initial vanilla JS study mode and flashcard DOM controller.
- `index.vanilla.html`: Initial HTML layout structure.
- `style.css` / `style.vanilla.css`: Initial CSS styling.
- `quiz.html` / `quiz.js` / `quiz.css`: Early standalone 120-minute quiz simulation prototype.
- `data.js`: Early static question array.

### Note
These files are retained solely for auditability and historical reference. The active production application is fully modularized under `src/` and built using `npm run build` via Vite.
