# claude-certification

> 🚀 **Comprehensive Anthropic Claude Certification Preparation Platform** covering **CCAO-F**, **CCA-F**, and **CCA-P** with 305 authentic questions, in-depth Hinglish + English concept breakdowns, timed exam simulator, and searchable Question Bank.

---

## 🎯 Supported Certifications

| Certification | Title | Questions | Target Modules |
| :--- | :--- | :---: | :--- |
| **CCAO-F** | Claude Certified Associate - Foundations | 110 | Core Capabilities, Context Window, Prompt Engineering, Hallucinations, Embeddings, Evaluation |
| **CCA-F** | Claude Certified Architect - Foundations | 85 | Architecture, Prompt Caching, Extended Output, Model Selection (Haiku/Sonnet/Opus), Latency/Cost |
| **CCA-P** | Claude Certified Architect - Practitioner | 110 | Tool Use & Function Calling, Multi-Agent Systems, RAG Pipelines, Citations, System Prompts, Security & Guardrails |

---

## ✨ Features

- **🎓 Study Mode**: Topic-by-topic interactive exploration with Master Formula cards, Hinglish explanations, daily life analogies, practical good vs. bad examples, and option-by-option failure breakdown tables.
- **⏱️ Timed Exam Simulator**: 120-minute realistic exam environment with real-time countdown, question palette with review flags, auto-submit, local storage state persistence, and diagnostic scorecard.
- **🔍 Smart Question Bank**: Instant command search, jump-to-question navigation, interactive Self-Test mode (hide/reveal answers), bookmarking, and option failure critique tables.
- **🌌 Cosmic Dark Mode UI**: Built with modern glassmorphism, Plus Jakarta Sans & JetBrains Mono typography, 44px accessible touch targets, and WCAG AA/AAA contrast.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Vanilla CSS (Custom Design System, Glassmorphism, Responsive CSS Grid/Flexbox)
- **State Management**: Reactive state hooks with `localStorage` persistence
- **Icons**: Lucide React

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/suneelkumarr/claude-certification.git
cd claude-certification
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```
